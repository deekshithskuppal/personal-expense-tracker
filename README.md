# 💰 Personal Expense Tracker

## 📌 About the Project
The Personal Expense Tracker is a Python-based mini-project that helps users record their daily expenses, calculate total spending, and visualize expenses using charts.

## ✨ Features
- Add expense amount, category, and description
- Record the date of each expense
- Store expenses in a CSV file
- Calculate total spending
- Display category-wise expense summaries
- Visualize spending using a bar chart

## 🛠️ Technologies Used
- Python
- Google Colab
- Pandas
- Matplotlib
- CSV

## ▶️ How to Run
1. Open the Jupyter notebook in this repository.
2. Open Google Colab.
3. Upload the notebook to Google Colab.
4. Run the code cells in order.
5. Enter expense details and view the report.

## 📊 Sample Output
The program displays expense records, total spending, category-wise summaries, and a bar chart.

## 🎯 Project Objective
To help users understand and manage their daily spending through a simple Python application.
